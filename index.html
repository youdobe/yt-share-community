▶ YT Share Studio
브라우저 전용 · GitHub 자동 업로드

유튜브 · 커뮤니티 공유 카드

유튜브와 디시인사이드·에펨코리아·루리웹 게시글을 지원합니다. 제목·설명·썸네일을 설정해 공유 링크를 만들 수 있습니다.
별도 설치는 필요 없으며, 최초 1회 GitHub에서 제한된 권한의 토큰을 발급해야 합니다.

① 공유할 링크 설정

공유 카드를 클릭하면 이 주소로 이동합니다.

YouTube는 oEmbed 정보 조회를 시도합니다. 커뮤니티는 브라우저 보안 정책으로 자동 조회가 제한될 수 있습니다.

원본 영상 설명 전문도 가져오기 (선택 사항)

YouTube Data API v3 키를 이미 보유한 경우에만 입력하세요. 이 키는 코드에 저장되지 않습니다. 키가 없다면 위의 자동 안내문을 사용할 수 있습니다.

커뮤니티 글은 URL을 입력하고 조회를 시도하세요. 실패하면 아래 제목·설명·이미지를 직접 지정하면 됩니다.

이미지 주소를 이용하는 경우, 상대방이 해당 이미지에 접근할 수 있어야 합니다. 확실한 공유를 원하면 아래 파일 업로드를 사용하세요.

참고 링크에서 불러오거나 직접 이미지를 선택하세요.

이 주소를 기준으로 공유 URL과 이미지의 절대 주소를 생성합니다. 실제 공개된 사이트 주소를 입력하세요.

② GitHub 자동 업로드

현재 저장소: youdobe / yt-share-community · 브랜치: main

⚠ 토큰은 서버나 브라우저 저장소에 저장하지 않습니다. 자동 업로드를 할 때마다 다시 입력해야 합니다. 공유하지 마세요.

GitHub 토큰 생성 페이지 열기 · 저장소는 Only select repositories → yt-share-community, 권한은 Contents → Read and write로 설정하세요.

② 미리보기

썸네일 미리보기
공유용 정보 · 클릭 시 A 링크로 이동
여기에 공유용 제목이 표시됩니다
설명을 입력해 보세요.
공유 사이트 주소
알아둘 점
이 앱은 원본 게시글이나 영상의 정보를 수정하지 않고 별도 공유 카드를 만듭니다. 미리보기에는 사용자 지정 정보가 표시되며 실제 출처는 별도로 확인할 수 있습니다. 공유 링크가 공개된 뒤 카카오톡에서 테스트하세요.

③ 공유 방법

  1. 실제 이동할 링크 A 입력 → 참고 링크 B에서 정보 가져오기 (실패 시 직접 입력)
  2. GitHub에서 발급한 Fine-grained 토큰 입력
  3. 「GitHub에 자동 업로드」 클릭
  4. 생성된 URL을 카카오톡으로 전송
  5. 배포 후 미리보기와 이동 동작 확인

외부 이미지 URL은 원본 서버 정책에 따라 표시되지 않을 수 있습니다. 직접 업로드한 이미지는 GitHub에 저장됩니다. ZIP 수동 생성도 가능합니다.

설정은 브라우저에 자동 저장되지만 다른 PC와 자동 동기화되지는 않습니다. 설정 파일 저장/가져오기를 사용할 수 있습니다.
